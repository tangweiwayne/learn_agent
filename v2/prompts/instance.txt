## 常用写法

新建文件（注意结束符加单引号，防止 $ 被展开）：
```bash
cat <<'PYEOF' > newfile.py
print("hello")
PYEOF
```

带行号看文件的某几行：
```bash
nl -ba somefile.py | sed -n '10,30p'
```
